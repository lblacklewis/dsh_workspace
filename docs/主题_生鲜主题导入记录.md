   detail_data / detail_default_data / theme_data / theme_default_data

## 坑
- PowerShell 的 ConvertFrom-Json **不会**把 JSON 里的 `\/` 反转义成 `/`，
  解析后的字符串里是**字面反斜杠+斜杠**，正则要写 `images\\/` 而不是 `images/`
- eb_theme 的 up_time / add_time / *_update_time 都是 **int**，
  写 `NOW()` 会报 `Out of range value for column 'up_time'`，要用 `UNIX_TIMESTAMP()`
- 主题自带的「超级组件」里的商品链接指向原店铺商品，本库没有 → 商品位显示灰色占位块
  （包内说明也提示「超级组件里面的链接请自行修改调整」）
