## 4. 日常开发命令（**最常需要的两段**）

### 4.1 ⚠️ 改 Java 后端 —— 在**服务器上**编译，不是本地

后端源码在服务器 `/opt/storapp/crmeb`，服务器有 mvn + JDK8，`~/.m2` 已预热。

```powershell
# 1) 本地改完 .java 后，上传（用 ssh_upload 或 scp）
#    建议改完先 md5sum 比对，防止上传截断

# 2) 服务器上编译（只构建需要的模块，-am 带上依赖）
ssh root@82.156.226.192
cd /opt/storapp/crmeb
mvn -q -DskipTests -pl crmeb-admin,crmeb-front -am clean package

# 3) 重启
bash /opt/storapp/start.sh
```

- **改 `crmeb-service` 必须同时重建 admin 和 front**（两个 jar 都依赖它）
- 编译约 **45 秒**（预热后）
- 产物：`crmeb-admin/target/Crmeb-admin.jar`(20600)、`crmeb-front/target/Crmeb-front.jar`(20610)
- 日志：`/opt/storapp/admin.log`、`/opt/storapp/front.log`（**很大，别整 cat，用 grep**）
- ⚠️ 服务里 `log.info` **不落盘**（只留 DEBUG/SQL），别只靠 grep 判断代码跑没跑，**要看数据库结果**

### 4.2 改前端 —— 本地构建 + 部署脚本上传

**PC 后台（admin）**

```powershell
cd admin
$env:NODE_OPTIONS="--openssl-legacy-provider"; $env:NODE_ENV="production"
npm run build:prod                      # 约 3-5 分钟
cd ..\docs
.\deploy-admin.ps1 -Apply               # 打包+分块上传+原子换目录+重注入样式层
```

**H5（app）**


> 我为这个坑排查了很久（详见交接文档坑 20）。`unpackage` 那份是陈旧副本，已删。

**只改样式层（不重新构建）** —— 最快
