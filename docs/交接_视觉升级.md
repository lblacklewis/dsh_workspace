## 三、首页装修数据的状态（重要，别踩）

首页装修存在 `eb_theme.home_data`（也 `home_default_data`，**两个都要写**）。当前状态：

- 大小 **106,790 字节**
- **`json.loads` 解析失败**：`Expecting ',' delimiter: line 1 column 75316`
- 出错位置附近是富文本字段：`ext":{"val":"<p data-we-empty-p=\"\" style=\"text-align:center;\">...`
  —— 看起来是后台富文本编辑器写入时把引号转义坏了

**含义**：
1. 想改首页结构（加/删区块）**必须先修这个 JSON**，否则改完后台一保存可能整个首页崩掉
2. 在修好之前，**视觉改动只能走 CSS 注入层**（`docs/h5-modern.css`），这条路已验证可行且可回滚
3. 修 JSON 的建议做法：导出 → 修引号转义 → `json.loads` 验证通过 → 再回写。**不要直接盲改**

## 四、视觉升级的方向（建议）

用户说"毛坯房"，指的是**页面缺乏层次和内容密度**。零敲碎打的图标/图片替换解决不了。建议按这个顺序做：

### 优先级 1：服务保障条（纯 CSS 可做，零风险）
在轮播下方加一条「正品保障 · 药师审核 · 隐私配送 · 24h 发货」的图标横条。
医药类目这一步很关键 —— 用户买药最在意的是**信任**，而不是花哨。
（需要一个注入 HTML 的方式：目前只有 CSS 注入，要加 DOM 得先有 HTML 注入层）

### 优先级 2：页面底色 + 卡片化
现在是纯白/浅灰，区块之间没有视觉分隔。
改成：**浅青灰底色 + 白色圆角卡片浮在上面**，区块间距加大。
纯 CSS 就能做，收益大。

### 优先级 3：商品卡加标识
处方药/OTC 标识、24h 发货、医保等标签。需要商品数据支持
（`eb_store_product` 有 `is_rx` 字段可用；其他标签要加字段）。
**注意**：不要加不存在的促销标签（原 banner 写"满 99 减 20"就是假促销，已改掉）。

### 优先级 4：健康科普区
内容模块有 2 篇文章（`eb_article`）。做一个「用药科普」卡片区能显著提升内容密度。
需要改 `home_data`（即先解决第三节的 JSON 问题）。

### 优先级 5：分区标题加「查看全部 >」
纯 CSS + 现有 DOM 能做一部分，完整做要改 `home_data`。

## 六、必须记住的坑

1. **uni-app H5 的 `<image>` 编译成 `<uni-image><div style="background-image">`**
   —— CSS 宽高要打在内层 div 上，只写 `img`/`image` 不生效（已踩）

2. **PowerShell here-string 嵌在哈希表里会被解析器搞坏**
   —— 生成脚本用 **Node** 写，不要用 PowerShell（已踩，脚本直接没跑起来）

3. **`.ps1` 必须 UTF-8 with BOM**，否则中文乱码 + 解析错误

4. **banner viewBox 比例必须匹配显示区**（750×392 vs 362×189），否则 cover 裁切

5. **`fullPage` 截图会把 `position:fixed` 元素画在视口位置**
   —— 底部导航/弹层看着像跑到了页面中间，**那是截图假象不是 bug**（已踩，用视口截图验证过）

6. **本机 shell 出网被沙箱拦**，服务器可以。下载图片要在服务器上 `curl`

7. **替换静态资源走同名文件覆盖**，不动 `home_data`（那个 JSON 现在解析不了）

## 八、下一步建议

### 本会话为什么在这里结束（给接续的人看，别误判）

2026-10-29 核查了上下文配置，与 `AGENTS.md` 里记的有出入，以 settings.yaml 为准：

| 项 | 值 |
|---|---|
| 网关 api.scnet.cn 真实上限 | 1,048,576 tokens |
| DSH `contextWindow` | **500,000**（不是 1M） |
| DSH 自动压缩阈值 | 500,000 × 0.8 = **400,000** |

**为什么还是选择开新会话**：本会话的 `session.v3.jsonl.zstd` 已达 **8.95 MB**，
而 AGENTS.md 记录的翻车实例是 **8.79MB 后持续 400 死锁**（超网关上限时返回的
`ContextWindowExceededError` 被包装成通用文案，DSH 认不出→不自动压缩→会话锁死）。
8.95 > 8.79，所以主动收尾，而不是赌它还能撑。

**注意**：文件体积只是旁证，不等于上下文 token 数 —— 本机没有 zstd/7z/python
`zstandard` 可以解压成精确 token 数，所以**无法直接测量**。如果要精确量化，
先在机器上装一个 zstd 解压工具。
