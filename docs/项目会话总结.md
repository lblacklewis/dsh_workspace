## 🏗️ 技术架构

```
Admin前端(Vue2) ──代理──→ :80/nginx ──→ Admin API :20600 (SpringBoot)
移动端(uni-app) ──直连──→ :80/nginx ──→ Front API :20610 (SpringBoot)
                                        ├── MySQL :3306
                                        └── Redis :6379
```
