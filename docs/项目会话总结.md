# 附：TermDeck（本仓库中的另一个项目）

`termdeck/` 是本仓库里的独立项目：一个 Electron 桌面 SSH 客户端，
三栏布局 + dockview 可拖拽分屏终端，与 StorApp/CRMEB 无关，互不影响。

- **详细总结**：见 `termdeck/docs/项目会话总结.md`
- **验证方式**：`cd termdeck && npm run verify`
  （typecheck + 15 个探针套件 + 11 套主题 × 5 页面对比度审计）
- **说明**：它是自研实现，未使用 Termius 的任何代码或素材；仅参考其通用布局模式。

## 本次（第12轮）改动

| 项目 | 内容 |
|------|------|
| 字体可选 | 枚举系统已安装字体（Windows 走 .NET，Linux 走 fc-list，失败退回短名单），芯片式选择 + 实时预览 |
| 光标频闪 | 改用自绘 CSS 驱动（xterm 未为其 blink class 提供任何样式），速率可设 |
| 同时输入 | 新增广播按钮，一键把输入发送到所有打开的会话 |
| 风格精致化 | 圆角梯度、双层柔和阴影、边框按主题派生柔化、焦点光晕 |
| 移除行内图标 | 会话行不再显示连接/编辑/删除三个图标（双击连接，右键菜单编辑删除） |

## 本轮修复的隐患

- 工作区在切换栏目时被卸载，导致 dockview 实例被销毁，在别的页面建立的会话窗格无处渲染（表现为"Open sessions 里有、界面上没有"）。
- `dockview.toJSON()` 的结果无法结构化克隆，直接过 IPC 会静默丢失布局，需先序列化为字符串。
- 右键菜单被带 `transform` 的祖先当作包含块，被推到屏幕外，改为 portal 到 `<body>`。

### 家庭电脑无缝衔接步骤

1. `git clone git@github.com:lblacklewis/dsh_workspace.git`
2. `cd dsh_workspace && .\setup.ps1`（把 .dsh 部署到 ~/.dsh）
3. 手动配置 `~/.dsh/.credentials.yaml`（双 key，仓库只留 example 模板）
4. `dsh web` 启动，待办组件随 profile 自动加载

> ⚠️ 家/公司两台机器的 `dsh web` 要访问同一套数据，需各自独立配置 key；会话记忆通过仓库 `.dsh/sessions` 同步。
