## 🗄️ 数据库初始化

```bash
# 1. 创建数据库
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS java_dev DEFAULT CHARSET utf8mb4;"

# 2. 创建用户
mysql -u root -p -e "CREATE USER IF NOT EXISTS 'java_dev'@'localhost' IDENTIFIED BY 'NPKntRXcCrx2AZ3i';"
mysql -u root -p -e "GRANT ALL PRIVILEGES ON java_dev.* TO 'java_dev'@'localhost'; FLUSH PRIVILEGES;"

# 3. 导入SQL
mysql -u java_dev -pNPKntRXcCrx2AZ3i java_dev < crmeb\sql\Crmeb_v3.0.sql
```

## 🚀 启动方式

### 方式一：一键部署（Windows）
```bash
# 在项目根目录运行
deploy.bat
```

### 方式二：分步启动

```bash
# 1. 后端编译
cd crmeb
mvn clean package -DskipTests

# 2. 启动 Admin 后端（端口 20600）
java -jar crmeb-admin\target\crmeb-admin-0.0.1-SNAPSHOT.jar --spring.profiles.active=dev

# 3. 启动 Front API（端口 20610）
java -jar crmeb-front\target\crmeb-front-0.0.1-SNAPSHOT.jar --spring.profiles.active=dev

# 4. 启动 Admin 前端（端口 8080）
cd admin
npm run dev
```

### 访问地址
| 服务 | 地址 |
|------|------|
| Admin 管理后台 | http://localhost:8080 |
| Admin API | http://localhost:20600 |
| Front API | http://localhost:20610 |
| Swagger 文档 | http://localhost:20600/doc.html |

## 🎨 品牌定制

编辑 `admin/src/config/brand.js` 修改：
- `name` - 系统名称
- `logo` - Logo 地址
- `primaryColor` - 主题色
- `copyright` - 版权信息
