## 🚚 迁移到新服务器

### 迁移清单

| 序号 | 步骤 | 耗时 |
|------|------|------|
| 1 | 安装基础软件 (JDK8/Maven3/MySQL8/Redis7/Nginx) | 15 min |
| 2 | 复制 Java JAR 文件 | 2 min |
| 3 | 导出/导入数据库 | 5 min |
| 4 | 复制静态文件目录 | 2 min |
| 5 | 复制 Nginx 配置 | 1 min |
| 6 | 复制启动脚本 | 1 min |
| 7 | 配置防火墙/安全组 | 3 min |
| 8 | 启动服务 + 验证 | 5 min |
| **合计** | | **~35 min** |

### 1. 安装软件

```bash
# Ubuntu/Debian
apt-get update -qq
apt-get install -y openjdk-8-jdk mysql-server redis-server nginx maven

# CentOS/RHEL
yum install -y java-1.8.0-openjdk mysql-server redis nginx maven
```

### 2. 复制 JAR 文件

```bash
# 从旧服务器
scp -r root@旧IP:/opt/storapp/crmeb/crmeb-admin/target/Crmeb-admin.jar ./
scp -r root@旧IP:/opt/storapp/crmeb/crmeb-front/target/Crmeb-front.jar ./

# 放到新服务器
scp Crmeb-admin.jar root@新IP:/opt/storapp/crmeb/crmeb-admin/target/
scp Crmeb-front.jar root@新IP:/opt/storapp/crmeb/crmeb-front/target/
```

### 3. 数据库

```bash
# 旧服务器导出
mysqldump -u root java_dev > java_dev_backup.sql

# 新服务器导入
scp java_dev_backup.sql root@新IP:/tmp/
ssh root@新IP
mysql -u root -e "CREATE DATABASE java_dev DEFAULT CHARSET utf8mb4;"
mysql -u root -e "CREATE USER 'java_dev'@'localhost' IDENTIFIED BY 'NPKntRXcCrx2AZ3i';"
mysql -u root -e "GRANT ALL ON java_dev.* TO 'java_dev'@'localhost';"
mysql -u root java_dev < /tmp/java_dev_backup.sql
```

### 4. 静态文件

```bash
# 打包 → 传输 → 解压
tar -czf www-storapp.tar.gz /var/www/storapp/
scp www-storapp.tar.gz root@新IP:/tmp/
ssh root@新IP "cd / && tar -xzf /tmp/www-storapp.tar.gz"
```

### 5. Nginx 配置

```bash
scp /etc/nginx/sites-available/storapp root@新IP:/etc/nginx/sites-available/
ssh root@新IP "ln -sf /etc/nginx/sites-available/storapp /etc/nginx/sites-enabled/ && nginx -t && systemctl reload nginx"
```

### 6. 启动脚本 + 图片资源

```bash
scp /opt/storapp/start.sh root@新IP:/opt/storapp/
scp -r /opt/storapp/crmeb/crmebimage/ root@新IP:/opt/storapp/crmeb/
scp -r /opt/storapp/images/ root@新IP:/opt/storapp/
```

### 7. 防火墙

```bash
ufw allow 22/tcp && ufw allow 80/tcp && ufw allow 8092/tcp
ufw allow 20600/tcp && ufw allow 20610/tcp
ufw enable
```

### 8. 启动 + 验证

```bash
bash /opt/storapp/start.sh
curl localhost:20600/doc.html   # → 应返回 Swagger 页面
curl localhost/                 # → 应返回 StorApp 管理后台
curl localhost:20610/api/front/index  # → 应返回 JSON 数据
```

## 🛠️ 本地部署命令

```powershell
# 一键部署 (Windows PowerShell)
.\deploy.ps1 -Target admin     # 部署管理后台
.\deploy.ps1 -Target h5        # 部署移动端 (需先在 HBuilderX 中发行)
.\deploy.ps1 -Target all       # 全部部署
```
