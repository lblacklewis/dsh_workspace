# 新机器恢复清单

> 换电脑后，按这个顺序操作即可完全恢复开发环境。

## 1. 克隆仓库

```cmd
git clone git@github.com:lblacklewis/dsh_workspace.git
cd dsh_workspace
git checkout 3.0
```

## 2. 恢复 DSH 配置

```powershell
.\setup.ps1
```

> 然后手动把 API key 填到 `.dsh\.credentials.yaml`

## 3. 安装本地依赖

```cmd
cd admin
npm install
```

> JDK、HBuilderX 需要单独安装（下载链接见下方）

## 4. 启动开发

```cmd
:: Admin 前端
cd admin
npm run dev -- --port 8080

:: 移动端 → 用 HBuilderX 打开 app 目录 → 运行到浏览器
```

## 5. 对 DSH 说这句话即可恢复上下文

> "恢复 StorApp 项目目标"
